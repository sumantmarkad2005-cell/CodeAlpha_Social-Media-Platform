# CodeAlpha_Social-Media-Platform

# Mini Social Media App

A simple full-stack mini social media platform built using **HTML, CSS, JavaScript**, **Node.js**, **Express.js**, and **MongoDB**.  
This project demonstrates core social media features such as user profiles, posts, likes, and basic backend API handling.

---

## 🚀 Features

- User model with followers & following
- Create posts
- Like posts
- View all posts in a feed
- RESTful API using Express.js
- MongoDB database with Mongoose
- Simple and clean frontend UI

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript (Vanilla)

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose ODM
